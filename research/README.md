# Research

Experiments run against the product, kept as they were run: the probes behind the counts in `docs/STATUS.md`
(`final_audit/`), the parser tournament (`parser_tournament/`, `docs/archive/PARSER-COMPARISON.md`), the skill
optimizer run (`skillopt/`, `docs/archive/SKILLOPT.md`), the Phase 1 fixture (`demo_proof/`, `docs/DEMO-PROOF.md`) and
the depth pass's sweeps (`depth_pass/`). They are not part of the product, not linted, and not run by the release gate.
They were run from `backend/experiments/`; scripts that find the backend by their own path expect that place.
