## What held up (checked and found sound)

- Memo HTML: every interpolated field (`document.name`, question, guidance, topic, conclusion, quote, titles, reviewer, note, ids, model, prompt hash, deep link) goes through `html.escape(quote=True)`; attributes are single-quoted and `'` is escaped. No XSS found. The DOCX goes through python-docx/lxml text nodes; `custom.xml` values are `xml_escape`d.
- `Content-Disposition` filenames are built from server-generated hex ids only (`evidence-{run.id}.zip`, `review-memo-{run_id}.docx`); the CSV uses a `batch_id` that must exist. No header injection.
- On-disk paths: originals are `{sha256}{suffix}` (suffix from `Path(name).suffix`, constrained by `read()` to `.docx/.pdf/.txt`); memos are `memo-{run.id}-{head[:8]}.docx`. No traversal into `data/`.
- `WORKBENCH_OLLAMA_URL` is env-only; no request-controlled URL reaches httpx. No SSRF.
- Identical runs started at once: the partial unique index `ux_runs_fingerprint_active` + `IntegrityError` → `active_run` path is correct; failed runs are new rows, so the immutability triggers never block a retry.
- Verifier ladder: casefold offsets survive `ß`→`ss` (verified both directions); `İ` folds to two code points and is correctly *not* matched by `istanbul`; bounded edges reject `able` in `unable` and `5 days` in `15 days`; label strip refuses a bare number (`15 days` under §1.5); typed tier distinguishes `12.1`/`12.10`, `1.5%`/`15%`, `1,500.00`/`1500`, `$`/`USD`, and finds `$ 1,500`, `1.5 %`, `thirty(30)days`, roman `(IV)` by casefold.
- SSE: subscribe-before-replay closes the gap; heartbeat re-reads the record so a run ended elsewhere ends the stream; `Last-Event-ID`/`?after` replay is consistent (the UI never uses it — it closes the source on the first error).
- Immutability triggers: recovery closes the stage row and commits before the run turns terminal; `_fail` rolls back and re-reads so a run ended by another writer is left alone.

## Notes per area

**Security.** Everything writable is reachable without auth by design (Cloudflare Access is the only gate); the two things that cross the trust boundary into third parties are the evidence pack (#8) and the memo (clean). The pack's `document/{name}` entry and the prompt's `CONTRACT: {name}` line both trust the multipart filename; one `os.path.basename` + a length cap fixes both.

**DoS.** The threadpool is the real admission controller (#1): `AdmissionController` bounds model calls but not waiting threads, and Starlette runs sync background tasks on the same 40-token limiter as every sync route. Either run workers on a dedicated executor/queue or make `acquire` time-bounded and the stage row open only after admission (#2). Regex cost is quadratic, not exponential (#14); the catastrophic-looking `HEADING_NUMBER` case is unreachable after `.strip()`.

**Verifier.** Correct and conservative; the two real defects are outside it: UTF-16 drift in the pane (#7) and the 6000/5000 window mismatch (#6). The pack's `verify.py` should be generated from, or tested against, `tokens.py` (#22).

**Policy.** `parse_rule` is the weak link (#3, #4): it needs topic scoping (the mention nearest a notice/termination cue, or the one the model's `required` names when it is in the guidance) and a floor-vs-ceiling decision that looks at the words *before* the duration, not a symmetric window; `evaluate` should refuse to compute when the guidance contains more than one duration and none was selected. Range language and hyphenated forms (#13) are parser additions.

**Lifecycle.** The 41-minute window is a derived constant that forgot queue time (#2) and the pre-first-stage gap (#16). Recording `queue_wait_ms` on the stage row (it is already measured) and treating "queued" as progress would fix #2 without touching the window.

**API.** Error shapes are consistent (`{"detail": str}` vs FastAPI's list, both handled by the client); 404 for a body-referenced unknown id (`POST /api/runs`, `POST /api/memos`) is consistent across routes. Pagination is absent everywhere; the 500/200 caps silently hide the oldest records (#18). Path leak in `/api/engineering/experiments` (#19).

**Interface.** The follower's state machine is sound for failed/never-existed/gone ids (each ends in `viewError` or a finished failed run with a retry); the hole is the `disconnected` phase (#9) and the absence of any 401/302 handling (#9). Enter in the composer is not disabled while a run is in flight (the button is), so a second question abandons the first on screen while it keeps running. The withheld drawer prints the raw `sec_N` handle ("the model cited sec_3").

**Reader.** DOCX structure is style-only (documented) and numbering via `w:numPr` is lost (documented), but the TXT/PDF heuristic (#11) and style-level hidden text (#12) are undocumented and affect what the model reads and what the record claims it read.
